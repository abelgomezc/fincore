# banking-app

Aplicacion digital para clientes finales del banco.

## Objetivo

Entregar una experiencia bancaria digital moderna, segura y escalable para clientes finales.

## Responsabilidad

Gestionar la experiencia del cliente final, incluyendo consulta de cuentas, movimientos, transferencias, pagos y acceso a productos financieros.

## Contenido esperado

- Proyecto React / Next.js / Angular
- Componentes de UI reutilizables
- Servicios de autenticacion y autorizacion
- Integracion con API Gateway
- Configuracion de routing y estado global
- Pruebas unitarias y e2e

## Buenas practicas

- Atomic Design para componentes
- TypeScript estricto
- Storybook para documentacion de componentes
- Testing con Jest y Cypress
- Linting y formateo automatizado
- Accesibilidad WCAG 2.1
