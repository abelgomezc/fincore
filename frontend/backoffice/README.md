# backoffice

Panel de operaciones para el backoffice bancario.

## Objetivo

Proveer herramientas a las areas operativas para gestionar clientes, cuentas, transacciones y reportes del dia a dia.

## Responsabilidad

Gestionar operaciones internas, revision de transacciones, aprobaciones, consultas avanzadas y generacion de reportes operativos.

## Contenido esperado

- Proyecto React / Next.js / Angular
- Modulos de operaciones por dominio
- Tablas avanzadas con filtros y exportacion
- Integracion con servicios backend via API Gateway
- Manejo de roles y permisos granulares
- Auditoria de acciones de usuario

## Buenas practicas

- Modularizacion por dominio
- Paginacion server-side
- Internacionalizacion i18n
- Manejo de errores centralizado
- Logs de auditoria UI
- Soporte a temas claro/oscuro
